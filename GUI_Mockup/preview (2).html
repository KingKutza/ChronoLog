Shape Rule

A side line is not a separate horizontal lane. It descends from above, joins the Prime Line, shares that route for its active intersection, then exits downward.

Where two lines run together, render one thicker/shared segment with annotations on either side.

Interpretation

From the selected line’s perspective, it is the Prime Line. “Prime” is a viewing frame, not a permanent object type.

The month view is a set of intersections with June, not a stack of parallel calendars.
